# ValutaTrade Hub

Учебный проект для виртуальной торговли валютами, управления портфелем
и получения курсов из внешних API.

Автор: Николай Ульянов
Группа: М26-555

## Возможности

- Регистрация и вход пользователя.
- Покупка и продажа валют за виртуальные USD.
- Просмотр балансов и общей стоимости портфеля.
- Прямые, обратные и кросс-курсы.
- Получение курсов криптовалют через публичный API CoinGecko.
- Получение курсов фиатных валют через ExchangeRate-API.
- Локальный кэш курсов с проверкой срока актуальности.
- История измерений с защитой от дубликатов.
- Ручное и периодическое обновление курсов.
- Логирование операций и ошибок.

Поддерживаемые валюты: USD, EUR, GBP, RUB, BTC, ETH, SOL.
Приложение не выполняет реальные финансовые операции.

## Требования

- Python 3.12 или новее.
- Менеджер пакетов uv.
- Доступ к интернету для обновления курсов.

Приведённые команды терминала рассчитаны на Linux или WSL.

## Настройка API-ключа

Для ExchangeRate-API требуется персональный ключ.
Его можно получить на https://www.exchangerate-api.com/.

Создайте файл `.env` в корне проекта, рядом с `pyproject.toml`:

```dotenv
EXCHANGERATE_API_KEY=ваш_ключ
```

Образец переменных находится в `.env.example`.

Файл `.env` загружается автоматически. Переменные окружения имеют
приоритет над значениями из файла. После изменения ключа перезапустите
приложение.

`.env` исключён из Git. Не добавляйте настоящий ключ в исходный код,
README или `.env.example`.

CoinGecko используется через публичный API без ключа.

## Команды приложения

### Регистрация и вход

```text
register --username alice --password example123
login --username alice --password example123
```

При регистрации создаётся пустой портфель.
Для успешной покупки требуется достаточный баланс USD,
для продажи — достаточный баланс продаваемой валюты.

### Обновление курсов

Обновить оба источника:

```text
update-rates
```

Обновить только один источник:

```text
update-rates --source coingecko
update-rates --source exchangerate
```

При отказе одного источника сохраняются данные доступного источника.
При полном отказе API существующие данные не обновляются.
Подробности ошибок записываются в `logs/parser.log`.

### Просмотр курсов

```text
show-rates
show-rates --currency EUR
show-rates --top 2
show-rates --base EUR
```

Параметры:

- `--currency` — фильтр по валюте.
- `--top` — количество самых дорогих криптовалют по цене одной единицы.
- `--base` — валюта, относительно которой показываются курсы.

### Курс одной пары

```text
get-rate --from BTC --to USD
get-rate --from USD --to BTC
get-rate --from BTC --to EUR
```

Курсы рассчитываются из локального кэша.
Если необходимый курс отсутствует или устарел, выполните `update-rates`.

### Покупка и продажа

После входа пользователя:

```text
buy --currency BTC --amount 0.01
sell --currency BTC --amount 0.005
```

Количество должно быть положительным конечным числом.
При недостаточном балансе операция отклоняется.

### Просмотр портфеля

```text
show-portfolio
show-portfolio --base EUR
```

## Периодическое обновление

Планировщик запускается отдельной командой в терминале:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler
```

Первое обновление выполняется сразу. По умолчанию после каждой
попытки следует пауза 300 секунд.

Другой интервал:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler --interval 600
```

Обновление только криптовалют:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler --source coingecko
```

Остановка — Ctrl+C.

При ошибке API планировщик повторяет попытку после паузы.
При ошибке сохранения данных он останавливается.
Не запускайте несколько планировщиков или ручное обновление
одновременно с планировщиком: межпроцессная блокировка записи
не реализована.

## Настройки

Общие настройки находятся в секции `[tool.valutatrade]`
файла `pyproject.toml`:

- `data_dir` — каталог данных.
- `rates_ttl_seconds` — срок актуальности курса, по умолчанию 300 секунд.
- `default_base_currency` — базовая валюта портфеля.
- `log_file` — путь к журналу операций.
- `log_format` — формат сообщений журнала.

Настройки API, списки валют, таймаут запросов и интервал планировщика
заданы в `valutatrade_hub/parser_service/config.py`.

TTL проверяется по времени обновления конкретного курса.
Для кросс-курса учитывается более старая из используемых котировок.
Пауза планировщика и TTL — отдельные параметры; при задержках
обновления кэш может устареть.

## Хранение данных

- `data/users.json` — пользователи, хеши паролей и соли.
- `data/portfolios.json` — портфели и балансы.
- `data/rates.json` — последние курсы по валютным парам.
- `data/exchange_rates.json` — история измерений.

Кэш содержит раздел `pairs` и время `last_refresh`.
У каждой пары сохраняются `rate`, `updated_at` и `source`.

Историческая запись содержит валютную пару, курс, время, источник
и метаданные. Идентификатор формируется из пары и времени измерения.

Запись каждого JSON-файла выполняется через временный файл
с последующей заменой основного. Замена одного файла атомарна;
изменение нескольких файлов не является общей атомарной транзакцией.

## Структура приложения

- `core/` — модели, валюты, исключения, курсы и торговые операции.
- `infra/settings.py` — Singleton для загрузки настроек.
- `infra/database.py` — Singleton для чтения и записи JSON.
- `parser_service/config.py` — конфигурация парсера.
- `parser_service/api_clients.py` — клиенты внешних API.
- `parser_service/storage.py` — история и кэш курсов.
- `parser_service/updater.py` — координация обновления.
- `parser_service/scheduler.py` — периодическое обновление.
- `cli/interface.py` — команды и взаимодействие с пользователем.
- `decorators.py` — декоратор логирования.
- `logging_config.py` — настройка журналов.

Все перечисленные модули находятся внутри `valutatrade_hub/`.

## Журналы

- `logs/actions.log` — журнал операций приложения.
- `logs/parser.log` — журнал обновлений курсов.
